# Git 全局 DEVONthink 条目链接检查

此目录提供 DEVONthink 条目链接检查脚本及其 Git hook 入口。使用固定格式正则识别完整条目链接，不枚举 UUID，也不拦截单独出现的 UUID。

## 文件与行为

| 文件 | 职责 |
| --- | --- |
| item-link-guard | 检查 Git 暂存对象或待推送对象，命中后拒绝操作，不回显链接内容 |
| pre-commit | 提交前检查暂存内容和文件路径 |
| prepare-commit-msg | 检查暂存内容与初始提交信息 |
| commit-msg | 检查最终提交信息与暂存内容中的条目链接 |
| pre-merge-commit | 创建合并提交前检查暂存内容 |
| pre-applypatch | 应用邮件补丁后、创建提交前检查暂存内容 |
| pre-push | 检查待推送历史中的条目链接 |

检查直接读取 Git 对象，覆盖文本、二进制内容和符号链接目标，不按文件扩展名筛选。读取采用固定大小分块，并保留块边界重叠，以识别跨块出现的完整链接；同一次检查中的相同对象只读取一次。

推送检查覆盖待推送历史中的对象，因此中间提交加入、后续提交删除的链接仍会被拦截。新分支或本地缺少远端基点对象时会检查该引用的可达历史。

## 使用方式

运行环境需要 Git、POSIX shell 和 Perl 的核心模块 IPC::Open2。

将 item-link-guard 与各 hook 入口放在同一个专用目录，保留可执行权限，然后配置 Git 全局 hooks 路径：

```sh
git config --global core.hooksPath <目录绝对路径>
```

已有全局 hooks 时，将条目链接检查接入现有入口，保留其他检查的原有行为。
